# LJT-Homepage

Personal academic homepage of Junteng Liu, built on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

The site contains two pages:

- **About** (`_pages/about.md`): personal details, academic background, research experience, publications, skills, honors, and contact information.
- **Publications** (`_pages/publications.html`, rendered from the Markdown files in `_publications/`): the publication list.

Site-wide settings live in `_config.yml`, and the header menu is configured in `_data/navigation.yml`.
